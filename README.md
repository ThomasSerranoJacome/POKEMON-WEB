# Acerca de Pokemones 🎮

Página web que consume la [PokéAPI](https://pokeapi.co/) para buscar información sobre Pokémon.

## Tecnologías
- HTML, CSS, JavaScript
- PokéAPI (gratuita y pública)

## Funcionalidades
- Buscar Pokémon por nombre o número
- Filtrar Pokémon por tipo
- Ver cadena de evoluciones

## Cómo ejecutarlo
1. Abre la carpeta en Visual Studio Code
2. Clic derecho en `index.html` → **Open with Live Server**

## Estructura
pokedex/
├── index.html
├── styles.css
├── script.js
└── README.md
